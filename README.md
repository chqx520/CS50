## 怎么做CS50的作业

官方提供了环境搭建好的网页VS code，这个环境应该是可以运行check50，submit50等所有需要的命令的，你在里面写的源代码也能在你的GitHub找到
首先你需要能够注册GitHub，这里有个梯子是很重要的，如果你暂时不知道怎么搞到梯子（魔法，科学上网），也许编程的QQ群能帮助你

如果官方的网页VScode因为网络等问题不太适合你，或许你可以在本地的VS code操作，具体方法可以问ai

我目前的工作流是，先向ai询问本地配置的方法
配置好后，从官网获取题目，让ai翻译（如果你能读懂原文最好）
然后思考，编写源代码，有些题目不需要做完整的程序
这个时候向ai询问下载官方提供的代码的命令
后面就是慢慢写呗，可以submit到官网，最后可以得到一个电子版的证书
