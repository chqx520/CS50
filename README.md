# CS50 Problem Sets

## 为什么做这个库

CS50无疑是入门计算机的很优质的资源，除了听课，独立完成Psets也是学习的一环，这上面的题目相当优质。无论是出于为了自己还是能帮到更多人的目的，我觉得都可以做这个小项目

我会一直更新题目的源代码，里面会有一些注释和思路，代码风格比较贴近CS50，可读性我觉得是不错的。时间多的话我或许会一个题目提供多个版本，希望在你们遇到困难时有一点帮助

## 怎么做CS50的作业

官方提供了环境搭建好的网页VS code，首先你需要能够注册GitHub，这里有个梯子是很重要的，如果你暂时不知道怎么搞到梯子（魔法，科学上网），也许编程的QQ群很适合你

如果官方的网页VScode因为网络等问题不太适合你，或许你可以在本地的VS code操作，具体方法可以问ai
